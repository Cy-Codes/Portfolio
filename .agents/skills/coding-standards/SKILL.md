# Portfolio Coding Standards

Project-specific deltas not already captured in module `AGENTS.md` files. For human-facing onboarding examples and background rationale, see `CODING_STANDARDS.md` and `docs/architecture-decisions.md`.

| Rule Area | Automated Gate | What You Must Check Manually |
| :--- | :--- | :--- |

## 2. Core Language & Architecture Rules

- **Functional pipelines over loops:** Use `.map`, `.filter`, `.fold`, `.associate`, `.flatMap`, `generateSequence` (Kotlin/Swift), set-based `generate_series`/CTEs/`jsonb_agg` (SQL), and `jq`/`awk` (Bash).
- **Permitted loop exceptions (mandatory inline comment explaining why):**
  1. Unbuffered I/O or DB streaming (`ResultSet`, `ByteReadChannel`).
  2. Benchmarked hot paths where closure allocation measurably hurts GC.
  3. Bounded chunked DB maintenance batches avoiding lock escalation.
  4. Bounded Bash retry probes (`wait_for_url`) or iterating `readonly` arrays.
- **Immutability & CQS:** Keep domain models, DTOs, `QueryOptions`, `PagedResult<T>`, and FlowMVI `State`/`Intent`/`Action` `val`-only with read-only `List`/`Map`/`Set`. Separate pure queries (`get*`/`find*`/`parse*`/`to*`/`*QueryService`) from side effects (`execute*`/`create*`/`update*`/`delete*`/`*CommandService`). Keep HTTP `GET` handlers 100% read-only; send telemetry via `POST /api/v1/public/events`. Wrap `AutoCloseable` I/O in `.use { ... }`.
- **Clean layering & consolidation:** In `server-public`/`server-admin`, point dependencies strictly inward (`api` -> `application` -> `infrastructure` -> `domain`), keep concrete classes `final` with `private val` constructor DI, and consolidate shared helpers in top-level extensions (`QueryOptionsExtensions.kt`, `ApiErrorExtensions.kt`, `CallResultExtensions.kt`, `IdentifierValidationExtensions.kt`) or `scripts/lib.sh`.

## 3. Contracts, HTTP, Persistence & UI Deltas

- **Serialization & errors (`//core`):** Use frozen `PortfolioJson` (`encodeDefaults = true`, `ignoreUnknownKeys = true`, `explicitNulls = true`) and exhaustive `sealed interface ApiError` (`ValidationError` 400, `Unauthorized` 401, `Forbidden` 403, `NotFound` 404, `Conflict` 409, `InternalError` 500). Outside dev, `StatusPages` (`Throwable.toApiError`) must mask `500` causes behind a `traceId`.
- **HTTP & validation:** `POST` -> `201` + `Location`, `PUT` -> `200`/`404`, `DELETE` -> `204`/`404`, Postgres `23503`/`23505` -> `409 Conflict`, unmatched routes -> `404`. Generate UUIDs and `Clock` timestamps server-side. Validate pagination via `QueryOptions` (`MIN=1`, `DEFAULT=20`, `MAX=100`, CWE-190 offset overflow -> `400`) and sort fields via explicit allowlists (`validateAllowedSortField`).
- **Persistence (`server-db`):** Use Exposed 1.0 DSL (`org.jetbrains.exposed.v1.*`) inside `dbFactory.dbQuery` (`Dispatchers.IO` + `suspendTransaction`) or `executeUpdateNoReturning`; never use Exposed DAO entities, `SchemaUtils.create()`, or leak `Table`/`ResultRow`. Use `portfolio.*`/`analytics.*` schemas, `UUID`/`GENERATED BY DEFAULT AS IDENTITY`, `TIMESTAMPTZ`, B-Tree FK indexes, and 3-tier roles (`portfolio_migrator`, `portfolio_admin`, `portfolio_public`).
- **UI & R2 uploads:** Drive Compose layouts solely by `currentWindowAdaptiveInfo(supportLargeAndXLargeWidth = true)` `dp` tiers (`<600`, `600–839`, `840–1199`, `1200–1599`, `>=1600`) with modality layered separately; resolve `demo:<id>` blocks via `DemoRegistry` (explicit fallback card for unknown IDs); keep `iosApp` native SwiftUI + inline `ComposeUIViewController` islands. Verify R2/MinIO uploads on `confirm` (existence, size <= limit, magic-byte MIME, UUID `storage_key`, `nosniff`).
- **Docker & Bash:** Multi-stage non-root Dockerfiles with `-XX:MaxRAMPercentage=75.0`, OCI labels, pinned image tags (no `:latest`), `127.0.0.1` port bindings, `.env.example` parity, and meaningful `/health/ready` checks. Bash scripts require `#!/usr/bin/env bash`, `set -euo pipefail`, `source scripts/lib.sh`, `require_command`, `# Pure query:` / `# Side effect:` comments, `local`, `readonly`, `shfmt -i 4`, and parameterized `psql -v` via stdin.

## 4. Anti-Pattern & Remedy Catalog

| Anti-Pattern | Risk | Required Remedy |
| :--- | :--- | :--- |
| Mutable accumulators, `var`, `MutableList`/`MutableMap` | Race conditions, broken FlowMVI equality | `val` + `data class` + read-only `List`/`Map`/`Set`; `.map`/`.filter`/`.fold` |
| Magic numbers or raw string discriminators | Silent drift, brittle validation | `HttpStatusCode.*`, `QueryOptions.*`, `enum class`, `const val`, `readonly`, SQL `CHECK` |
| Writes inside `GET` (e.g., download counters) | Breaks HTTP idempotency & RO DB role | Keep `GET` read-only; emit `POST /api/v1/public/events` |
| Sharing `public` schema or superuser DB role | Excessive blast radius | Explicit `portfolio.*`/`analytics.*` + 3-tier roles |
| `SchemaUtils.create()` or editing merged `V*.sql` | Schema drift, Flyway checksum failures | One-shot Flyway migrator + append-only `V<n+1>__*.sql` |
| `SERIAL`, `TIMESTAMP`, unindexed FKs | Non-standard sequences, lost UTC, lock scans | `GENERATED BY DEFAULT AS IDENTITY`/`UUID`, `TIMESTAMPTZ`, B-Tree FK index |
| Reflection JSON or raw `500` exception leaks | Mangled `is*` booleans, credential leaks | `PortfolioJson` + `Throwable.toApiError(isDev)` with `traceId` |
| Unbounded `pageSize` or unchecked `(page - 1) * pageSize` | OOM / CWE-190 integer overflow | Clamp `1..100` and check overflow before SQL (`400`) |
| OS-branched UI or blobs in Postgres `BYTEA` | Broken resizing/tablets, WAL/heap bloat | M3 `dp` breakpoints; presigned R2/MinIO PUT + magic-byte verify |
| `:latest` images or secrets in repo/YAML | Non-deterministic deploys, leaked creds | Pinned tags, `.env.example`, runtime secret injection |

## 5. Pre-Finish Self-Review & Related Skills

1. No `mutableListOf`/`var` accumulators or un-commented loops?
2. Zero unnamed status codes, ports, limits, or string discriminators?
3. New `System::getenv` vars mirrored in `.env.example` and fail-closed in prod?
4. Public `GET` handlers strictly read-only; new routes covered by negative (`400`/`401`/`403`/`404`/`409`) tests?
5. Any new SQL migration appended as `V<n+1>__*.sql` with FK indexes and role grants?
6. Verification run **after** final edit? Follow `.agents/skills/` (`verify-change`, `db-migration`, `add-api-endpoint`, `web-verify`, `release-preflight`); see `CODING_STANDARDS.md` (human onboarding & examples) and `docs/architecture-decisions.md` (ADR trade-offs & external references).
