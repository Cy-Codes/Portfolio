# PostgreSQL & Flyway Migration Workflow

## 1. Never Mutate Committed Versioned Migrations

- Committed `server/server-db/resources/db/migrations/V*.sql` files are **strictly immutable**.
- Always append a new migration: `server/server-db/resources/db/migrations/V<n+1>__<snake_case_description>.sql`.
- Put idempotent views and pure SQL functions in `server/server-db/resources/db/migrations/R__portfolio_read_views.sql` (or a new `R__*.sql`).

## 2. Mandatory PostgreSQL 16 DDL Checklist

1. **Explicit schemas:** Every object belongs in `portfolio.*` or `analytics.*`—never `public`.
2. **Modern column types:** Use `UUID` or `BIGINT GENERATED BY DEFAULT AS IDENTITY` (never `SERIAL`), and `TIMESTAMPTZ` everywhere (never timezone-naive `TIMESTAMP`).
3. **Foreign key indexes:** Add an explicit B-Tree index (`CREATE INDEX ...`) on every `REFERENCES parent(id)` column.
4. **Function volatility:** Declare `IMMUTABLE`, `STABLE`, or `VOLATILE` on every SQL/PLpgSQL function.
5. **Three-tier least-privilege grants:**
   - Guard grants inside `IF EXISTS (SELECT 1 FROM pg_roles WHERE rolname = '...')` blocks (matching `V1__init_schemas_roles_and_tables.sql`).
   - Grant DML (`SELECT, INSERT, UPDATE, DELETE`) on `portfolio.*` to `portfolio_admin`.
   - Grant `SELECT` only on public `portfolio.*` objects to `portfolio_public` (never `UPDATE`, `DELETE`, or DDL).

## 3. Align Kotlin & SQL Verification

1. Update Exposed 1.0 DSL `Table` definitions in `server/server-db/src/.../tables/`, `RowMappers.kt`, and repositories in `PortfolioRepositories.kt`.
2. Update `server/server-db/db/tests/01_schema_structure_tests.sql` with any new tables, views, or role assertions.
3. Update `server/server-db/db/scripts/01_seed_dev_data.sql` if seed coverage is needed (set-based `generate_series` / CTEs only).

## 4. Verify End-to-End

1. Start fresh/migrated deps and run SQL structure assertions:
   ```bash
   ./scripts/up.sh deps --seed
   ./scripts/smoke.sh deps
   ```
2. Run repository unit tests + Konsist:
   ```bash
   ./scripts/verify.sh --fast --module server-db
   ```
3. Run the real Postgres + MinIO Testcontainers integration suite:
   ```bash
   ./kotlin test -m server-db -p jvm --include-classes="*PostgresAndMinioIntegrationTest*"
   ```
