# Server & Database Rules (`server/`)

Applies to `server/server-db`, `server/server-public`, and `server/server-admin`.

## Architecture & Boundaries

- **Compile-time split:** `server-public` must never import `codes.cy.portfolio.server.admin.*`; `server-db` must never import `io.ktor.server.*`; neither `server-public` nor `server-admin` may import `org.jetbrains.exposed.*` directly.
- **Inward layering (`server-public`, `server-admin`):** `api` (Ktor routes, `StatusPages`, request parsing) -> `application` (`*QueryService` & `*CommandService`) -> `infrastructure` (`server-db` adapters, `BlobStorage`, JWT/auth) -> `domain` (`*Config`, pure validation, `//core` contracts). Keep concrete classes `final` with primary-constructor `private val` DI.
- **Exposed 1.0 DSL-only:** Use `org.jetbrains.exposed.v1.*` DSL queries inside `dbFactory.dbQuery` / `newSuspendedTransaction(Dispatchers.IO)` mapped into immutable `data class` models. Never use Exposed DAO active-record entities, never run `SchemaUtils.create()`, and never leak `Table` or `ResultRow` outside `server-db`.

## HTTP, Security & Postgres Standards

- **Strict CQS:** `GET` endpoints (including `/api/v1/public/documents/{id}/download` and `/read/{slug}`) perform zero DB writes.
- **Pagination & validation:** Validate `(page - 1L) * pageSize` via `QueryOptions` before SQL (`400` on overflow, CWE-190); use explicit column allowlists for sorting (`validateAllowedSortField`).
- **Errors & auth:** Map domain/SQL exceptions (`23503`/`23505` -> `409 Conflict`) to `//core` `ApiError` via `StatusPages`; sanitize `500` errors with `traceId` outside dev. Keep admin auth fail-closed (never weaken prod allowlist or dev-JWT gates).
- **PostgreSQL 16:** Tables belong strictly in `portfolio.*` or `analytics.*` (never `public`). Use `UUID` or `GENERATED BY DEFAULT AS IDENTITY` (never `SERIAL`), `TIMESTAMPTZ`, B-Tree indexes on every FK, explicit `IMMUTABLE`/`STABLE`/`VOLATILE` on functions, and 3-tier roles (`portfolio_migrator`, `portfolio_admin`, `portfolio_public`). Committed `migrations/V*.sql` files are immutable.
